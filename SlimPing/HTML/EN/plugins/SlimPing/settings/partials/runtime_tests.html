Runtime Tests

SlimPing only has context once it is running inside Lyrion, so some of its logic cannot be exercised by offline tests. These runtime tests run in the server process and check the parts that are not reachable over the OpenSubsonic API: CUE and DSD seek time formatting, the reportPlayback scrobble threshold, the Alternative Play Count pass tracker and the Ratings Light rating conversion. They need no client, no configured library path and no network access.
