External Metadata

SlimPing integrates with the Music & Artist Info plugin for lyrics and artist biographies. To protect upstream services from excessive requests, external lookups are gated by a concurrency cap and a per-minute rate limit. This plugin is designed for small-scale personal use with a modest number of active Subsonic clients, not as a large-scale streaming proxy. Defaults are tuned accordingly.

[% WRAPPER setting title="Artist Image Enrichment" desc="Serve local artist images from the Music & Artist Info plugin via the OpenSubsonic API endpoints getArtistInfo/getArtistInfo2. Auto enables automatically when MAI is installed with an Artist Image Folder configured. Off keeps the default cover-art behaviour. On force-enables (falls back gracefully if MAI is unavailable)." %] [% END %] [% WRAPPER setting title="Lyrics & Biography Fetching" desc="On Demand fetches only when a lyrics or artistInfo endpoint is called. For items not yet cached the first request triggers the external fetch but returns empty; some clients may not show lyrics until a second request. Off serves embedded lyrics only with empty biographies. Requires the Music & Artist Info plugin." %] [% END %] [% WRAPPER setting title="External Request Concurrency Cap" desc="Maximum number of external MAI requests (lyrics and biographies that need to go online) allowed in-flight at once. When the cap is reached, additional external lookups are skipped and retried on the next client request. Local cache hits are never throttled. Range 5–50, default 20." %]
[% END %] [% WRAPPER setting title="Request Rate Limit" desc="Maximum number of external MAI requests allowed per minute, across all users. When the limit is reached, further external lookups are queued and processed at the rate-limit cadence, ensuring upstream providers (Wikipedia, LRCLib, Genius) are never flooded. Range 1–60, default 10." %]
