Warning: Earlier plugin versions (<0.7.0047) could create orphaned tracks and playback records in the Lyrion database when serving audio via the 'Exotic' path. These appear as "No Album" / "No Artist" entries and fake albums in Recently Played. This operation finds and removes only SlimPing-created orphan data. Your real library data is never touched. Only ever run this if you are seeing orphaned tracks in your library or recently played list.

Two-step: First click counts the orphaned rows without deleting anything. Review the count, then confirm to execute the cleanup.

[% END %] [% WRAPPER setting title="Reset Database" desc="Delete every row from every table. The migration sentinel is also cleared so a fresh migration will run on next plugin load, re-populating users from the legacy prefs if they still exist." %]

Warning: This permanently deletes all users, API keys, stars, ratings, bookmarks, sessions, and shares. If you have not saved your user credentials separately you will be locked out. The action is audited in the server log. Proceed only if you understand the consequences.

The optional disk tier provides persistent backing for larger caches." %] [% WRAPPER setting title="RAM Cache" desc="In-memory cache always active — checked before every stream request. Complete entries serve at network speed with no transcode. Eviction is LRU — oldest complete entries are removed first when either cap is reached." %]
Default: 100 MB, 10 tracks. One in-flight entry may temporarily exceed the cap. Eviction stops at 80% of cap. Size changes require a plugin restart to take effect.
[% END %] [% WRAPPER setting title="Disk Backing Store" desc="Optional persistent storage under the LMS cache directory. Files are stored as paired AUDIO/JSON entries. Default: 2048 MB (2 GB). Oldest entries evicted first. Leave path empty for the default LMS cache location.
