OpenSubsonic Extensions

OpenSubsonic extensions are optional API capabilities that clients discover via getOpenSubsonicExtensions. Most extensions are always available; a few can be toggled per user.

Extension Versions Description Status
apiKeyAuthentication 1 API key-based authentication via ?k= or Authorization: Bearer header. Always on
formPost 1 Clients may POST parameters as application/x-www-form-urlencoded or multipart/form-data instead of query-string GET. Always on
jukeboxControl 1 Jukebox-mode playback control (play, stop, skip, volume). Requires a jukebox player to be assigned to the user. Always on
savePlayQueue 1 Persist the client's play queue on the server for cross-device resume. Always on
indexBasedQueue 1 Play queue tracks are referenced by index rather than by ID in savePlayQueue responses. Always on
songLyrics 1, 2 Structured (v1) and synchronised (v2) lyrics via getLyrics. Always on
songRating 1 Per-track user ratings (1-5) via setRating and getRating. Always on
star 1 Favourite tracks, albums, and artists via star/unstar. Always on
coverArtResize 1 Server-side cover art resizing via the size parameter on getCoverArt. Always on
playCount 1 Per-track play counts returned in getAlbum, getSong, and other API responses. Always on
playbackReport 1 Clients may report detailed playback state (starting, playing, paused, stopped) and position via reportPlayback.view. This enables rich Now Playing displays and timeline tracking. Per-user toggle
transcodeDecision 1 Client advertises preferred formats and bitrates; server returns the actual transcoding decision per stream. Always on
transcodeOffset 1 Support for seeking within transcoded streams via byte-range offsets. Always on
transcoding 1 Server-side audio transcoding (format and bitrate conversion). Always on

Per-User Toggle: playbackReport

The playbackReport extension allows clients to send detailed playback state updates. When disabled for a user, the reportPlayback.view endpoint returns error 50 for that user.
