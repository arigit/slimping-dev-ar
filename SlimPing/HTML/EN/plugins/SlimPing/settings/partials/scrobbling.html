Scrobbling

Feed completed plays from Subsonic clients into LMS's AudioScrobbler plugin (Last.fm / ListenBrainz). Requires the AudioScrobbler plugin to be installed and a gateway player to be selected. Scrobbling can be toggled per user in the Users section.

[% WRAPPER setting title="Gateway Player" desc="The LMS player whose AudioScrobbler account will be used to submit scrobbles. Only players with AudioScrobbler enabled are shown. All SlimPing scrobbles flow through this player." %] [% IF scrobble_gateway_stale %]
The saved gateway player “[% scrobble_gateway_player_name | html %]” no longer has an AudioScrobbler account configured. Scrobbling is paused until a valid player is selected below.
[% END %] [% IF !slimping_scrobble_players.size && !scrobble_gateway_stale %]

No players with AudioScrobbler enabled are currently connected.
