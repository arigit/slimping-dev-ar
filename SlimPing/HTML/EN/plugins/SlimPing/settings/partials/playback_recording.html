Playback Recording

When enabled for a user, completed plays from OpenSubsonic clients are recorded in the Lyrion Music Server library exactly as if the track had been played by a local player. This powers Recently Played, per-track and per-album play counts, Top Songs, and album rankings. Disable per user if you only want external scrobbling (Last.fm / ListenBrainz) without local Lyrion statistics.

What gets recorded:
• Play count — increments the track's play count in the Lyrion library, visible in getSong, getAlbum, getTopSongs, and album ranking queries (getAlbumList type=frequent).
• Last played timestamp — the track appears in Lyrion Recently Played (web UI, Material Skin, APC plugin) and album queries sorted by most-recently-played (getAlbumList type=recent).

What is NOT affected by this toggle:
• External scrobbling — Last.fm and ListenBrainz submissions are controlled separately by the "Scrobbling" setting above.
• Now Playing — the current track display in Subsonic clients is always updated regardless of this setting.
• Lyrion native playback — tracks played through Lyrion's own players always record statistics; this toggle only affects plays reported by OpenSubsonic clients via scrobble.view or reportPlayback.view.
