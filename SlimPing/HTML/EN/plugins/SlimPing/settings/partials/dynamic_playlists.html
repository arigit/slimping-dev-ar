When enabled, Dynamic Playlists that you have favourited in the Dynamic Playlists plugin are exposed as read-only 'smart' playlists to OpenSubsonic clients. Tracks are regenerated periodically and deduplicated across sessions with SlimPing keeping track of this.

Only Dynamic Playlists that can be populated with default or no runtime parameters, and are not set for context menu access, are exposed. If you have no eligible playlists, enable and favourite some in the Dynamic Playlists plugin to experiment with, then click Refresh below.
