Exotic Format Handling

Controls how SlimPing delivers exotic audio formats (DSD, high-res PCM) that cannot be played natively by any Subsonic client. These formats are always transcoded. The setting below chooses the target format when the client requests the 'original' quality.

Clients that explicitly request MP3 or a bitrate limit always receive MP3 regardless of this setting. This only affects requests where the client asks for the source format (format=raw/auto) or makes no format request.

[% WRAPPER setting title="Exotic Format Delivery" desc="When a client requests the original format of an exotic audio file (DSD, high-res PCM), deliver as:" %] [% END %] [% WRAPPER setting title="FLAC Sample Rate" desc="Output sample rate when delivering exotic formats as FLAC. All rates are integer divisors of DSD source rates or the PCM rate. Higher rates preserve more detail but produce larger files and not all Subsonic clients may be able to play the audio. Does not affect MP3 output." %] [% IF exotic_target == 'flac' && !cache_disk_enabled %]

DSD-to-FLAC transcoding is CPU-intensive. Enabling the persistent disk cache in Data and Cache Management is strongly recommended. Each transcode will be stored and reused, avoiding repeated decoding of the same tracks.

[% END %]

Note: DSD transcoding requires the DSDPlayer plugin (provides the dsdplay decoder). FLAC output at the selected sample rate, 24-bit stereo for DSD sources. Transcodes are cached on disk for repeat plays when the disk cache is enabled.

[% END %]
